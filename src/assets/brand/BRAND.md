# Social Teardown brand

Sibling of Inbox Teardown: condensed uppercase wordmark, light on near-black, one orange slash.

## Colors

| Role   | Hex       |
|--------|-----------|
| Ground | `#121214` |
| Ink    | `#F4F4F2` |
| Accent | `#D9622B` (the slash only) |
| Muted  | `#9A9AA0` (secondary text on ground) |

## Type

Anton (Google Fonts, SIL OFL 1.1, license in `Anton-OFL.txt`). All logo SVGs here are outlined paths, so they need no font installed.

## The mark

`SOCIAL/TEARDOWN`, all caps, 0.01em tracking. The slash is the accent color, skewed 6° forward, with about 0.035em of space on each side so it never touches the L or the T crossbar.

On the site, the header wordmark stays live text (same component as inboxteardown, with SOCIAL swapped in). Use these files everywhere else.

## Files

| File | Use |
|------|-----|
| `wordmark-on-dark.svg` / `.png` | Light ink, transparent background, for dark surfaces |
| `wordmark-on-light.svg` / `.png` | Dark ink, transparent background, for light surfaces |
| `avatar-monogram-1080.png` | Profile photo on Instagram, TikTok, X (survives the circle crop) |
| `avatar-stacked-1080.png` | Alternate square avatar, posts, cards |
| `og-default.svg` | Master for `public/og-default.png` |
| `public/favicon.svg`, `favicon.ico`, `apple-touch-icon.png` | Site icons |
| `public/og-default.png` | Default Open Graph and X card image, 1200x630 |

## Don'ts

No recoloring the slash, no gradients or shadows, no stretching. Keep clear space of at least the height of the slash around the mark.
